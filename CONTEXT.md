# Published Artifact Service

The Published Artifact Service keeps named static content available for people to open and browse.

## Language

**Artifact**:
A named static file tree with one current Version and zero or more retained earlier Versions.
_Avoid_: Site, project, published artifact

**Version**:
An immutable publication of an Artifact. One Version is current and is the content people receive when they open the Artifact.
_Avoid_: Build, revision, release

**Artifact Directory**:
The public homepage that lists all current Artifacts and lets people open them.
_Avoid_: Catalog, gallery, landing page
